## 1. 产品概述

### 1.1 背景与目标
绝味集团知识分散在个人电脑、聊天记录、项目文档中，缺少统一的沉淀、检索与复用机制。本产品构建**组织级 AI 知识库平台**：

- **沉淀**：按组织架构（集团 → 事业部 → 片区 → 中心 → 部门）建立多层级的公司知识库，同时支持个人知识库与项目知识库；
- **检索**：跨知识库全文搜索文档；
- **智能问答**（**核心卖点**）：基于所选知识库范围的 AI 问答（知识库提问 / Enjoy AI），答案可溯源到原文片段与页码，回答限定在已授权知识库范围内，杜绝"乱答/泄密"；
- **管控**：基于组织架构的细粒度权限（查看 / 下载 / 编辑 / 管理），支持管理员分级授权、临时分享授权、成员组复用。

### 1.2 目标用户
| 角色 | 说明 | 典型诉求 |
|---|---|---|
| 普通成员 | 全集团员工，可浏览/检索有权限的知识库 | 快速找到资料、AI 问答 |
| 知识库管理者 | 被授权管理某类型知识库（集团/公司/中心三级管理员） | 管理知识库内容与成员 |
| 系统管理员 | 平台级配置人员 | 空间域配置、知识库初始化、全局权限 |
| 个人用户 | 使用个人知识库 | 沉淀个人资料、收藏、复制公司文档到个人空间 |

### 1.3 产品范围
- **本期核心**：知识库总览与筛选、知识库管理（新建/编辑/删除/分享/权限）、文档管理（上传/预览/收藏/重命名/复制/删除）、文档检索、我的收藏、知识库提问（AI 问答）、成员管理（成员组）、权限管理。
- **平台管理**：空间域配置、知识库权限管理、知识库配置（初始化）、知识库管理者授权、我的分享。
- **AI 对话**：Enjoy AI 独立对话页（支持 `#` 提及知识库）。

## 2. 名词解释

| 名词 | 定义 |
|---|---|
| 空间域 | 一种知识库类型及其组织归属的配置单位，如"集团知识库"绑定"集团"层级。**岗位知识库的子类型（如鸭脖主业/廖记/集团）也作为空间域配置项管理**，可增删、启停。停用后该类型知识库不可再新建，已存在的可继续使用 |
| 知识库类型 | 集团知识库 / 公司知识库 / 中心知识库 / 项目知识库 / 岗位知识库 / 部门知识库 / 个人知识库；岗位知识库下挂子类型（配置化） |
| 岗位知识库 | 面向岗位场景的知识库，子类型由**空间域配置**动态生成（原型预置：鸭脖主业岗位知识库、廖记岗位知识库、集团岗位知识库），在范围树中勾选"岗位知识库"后按子类型平铺展示知识库（不做树展开） |
| 成员组 | 可复用的成员集合（组织/个人组合 + 默认权限），新建知识库时可整组引用 |
| 知识库管理员 | 按类型分级（集团/公司/中心），仅可管理对应类型知识库 |
| 系统知识库 | 系统自动创建的知识库（带"系统"徽标），不可删除，仅可编辑 |
| 分享 | 将知识库临时授权给组织或个人，可设有效期，到期自动回收 |
| 初始化 | 按"知识库配置"模板批量自动创建知识库并完成管理员/权限初始化 |

## 3. 角色与权限模型

### 3.1 权限类型
| 权限对象 | 权限项 | 继承规则 |
|---|---|---|
| 知识库 | 查看 / 下载 / 管理 | 高权限自动包含低权限（管理 ⊃ 下载 ⊃ 查看） |
| 文档 | 查看 / 下载 / 编辑 / 管理 | 高权限自动包含低权限（管理 ⊃ 编辑 ⊃ 下载 ⊃ 查看） |

### 3.2 管理员分级
| 管理员类型 | 可管理知识库 | 说明 |
|---|---|---|
| 集团知识库管理员 | 仅集团知识库 | 在"知识库管理 / 授权知识库管理者"中授予 |
| 公司知识库管理员 | 仅公司知识库 | 同上 |
| 中心知识库管理员 | 仅中心知识库 | 同上 |

> 当前用户（原型身份 God / 陈倩）为"公司知识库管理员"（员工号 10026），可见原型中管理按钮随知识库类型显隐。

### 3.3 授权对象维度
- **组织**：按组织树节点授权（勾选组织节点）；
- **个人**：在组织树中勾选末级个人或直接搜索添加；
- **成员组**：整组添加已有成员组。

### 3.4 关键权限逻辑
1. 创建者默认拥有所建知识库的管理权限；
2. 选择成员组后，组内成员默认获得知识库"查看"权限；
3. 组织继承：组织节点被授权后，其下级成员继承权限（原型中权限来源标注为"组织继承"）；
4. 文档权限与知识库权限相互独立，但**无权查看知识库的用户不可单独获得文档权限**（隐含约束，待确认）；
5. 系统知识库默认由管理员管理，普通成员仅按授权查看。

## 4. 功能需求

### 4.1 知识库总览与筛选（首页）

**入口**：左侧导航"知识库 → 企业知识库"。

#### 4.1.1 范围筛选树（左栏）
- 树形多选节点：`全部 / 集团知识库 / 公司知识库 / 中心知识库 / 项目知识库 / 岗位知识库 / 个人知识库 / 我的收藏`；
- **岗位知识库**为父节点，其子类型由**空间域配置**动态生成（原型预置 3 个子类型：鸭脖主业 / 廖记 / 集团），勾选后按子类型**平铺**展示对应知识库（不在树中展开子节点）；
- 支持多选，勾选结果决定：① 知识库卡片展示范围；② "搜索文档"的检索范围；③ "知识库提问"的默认问答范围；④ "新建知识库"可选的类型范围；
- 树节点带复选框与展开箭头，支持层级展开收起（空间域若配置父子关系则递归展示）。

#### 4.1.2 顶部工具栏
| 元素 | 行为 |
|---|---|
| 搜索框 + "搜索文档" | 输入关键词，在**已勾选知识库范围内**检索文档（未勾选时检索当前范围全部知识库），结果以列表展示：文档名、所属知识库、类型 |
| "全选"按钮 | 一键勾选/取消勾选当前可见知识库列表（KB 列表视图下联动行级复选框） |
| 成员管理 | 进入成员管理页（成员组配置） |
| 知识库提问 | 打开 AI 问答侧边抽屉（未勾选知识库时置灰） |
| 新建知识库 | 打开新建弹窗，类型下拉按当前 scope 过滤 |

> 进入任一知识库文档列表页后，顶部"成员管理 / 知识库提问 / 新建知识库"三个按钮隐藏，返回时恢复。

#### 4.1.3 知识库展示
- **卡片视图**（默认）：卡片含名称、类型、文档数、成员数、右上角 `···` 操作菜单；系统知识库带"系统"徽标；
- **列表视图**：表格列 = 全选复选框 | 知识库名称 | 类型 | 文档数 | 成员数 | 操作（`···`）；
- 两种视图共享分页（默认每页 10 条）与筛选；
- 勾选多个知识库后出现**批量操作栏**：批量删除、取消选择；全选 = 勾选当前列表全部行；
- 空态提示："当前筛选下暂无知识库，请调整筛选条件或搜索关键词。"

#### 4.1.4 知识库操作菜单（`···`）
| 操作 | 说明 |
|---|---|
| 编辑信息 | 修改名称 / 描述 / 类型 |
| 分享知识库 | 选择组织/个人 + 有效期，授权临时查看权限 |
| 权限管理 | 打开权限管理弹窗（成员范围 + 查看/下载/管理） |
| 删除知识库 | 仅对本人有管理权限且非系统知识库可执行，二次确认（"删除后无法恢复"） |

### 4.2 知识库文档列表页

**入口**：点击任意知识库卡片/列表行。

- 顶部：`← 返回知识库列表`、知识库名称、副标题"按上传时间倒序排列"、"上传文档"按钮；
- 文档列表：全选复选框 | 文档名称（含类型标签 PDF/DOC/WEB）| 上传时间 | 行内 `···`；
- 勾选文档后出现**批量操作栏**：批量删除、取消选择；全选 = 勾选当前页全部文档；
- 底部：文档总数 + 分页；
- 空态：无文档时显示提示。

#### 文档操作菜单（行内 `···`）
| 操作 | 说明 |
|---|---|
| 查看预览 | 打开预览弹窗（PDF 显示页数，侧栏展示"引用定位"页码+标题，点击定位） |
| 收藏文档 | 加入"我的收藏"（星标切换） |
| 复制到个人空间 | 选择目标个人知识库，生成独立副本（不影响原文档） |
| 权限管理 | 文档级权限（查看/下载/编辑/管理） |
| 重命名 | 修改文档名 |
| 删除 | 二次确认后删除 |

#### 上传文档
- 支持两种来源：**本地文件**（PDF / DOC / DOCX，可拖拽或选择）、**网页链接**（提取正文保存）；
- 上传过程展示文件名 + 进度条；说明文案"资料将自动解析并生成可引用内容"（AI 引用定位依赖解析结果）；
- 上传入口：文档列表页"上传文档"按钮。

### 4.3 我的收藏
- 左栏勾选"我的收藏"或进入收藏视图，展示全部收藏文档：星标 | 文档名 | 所属知识库 | 日期 | 类型；
- 支持取消收藏（星标）；点击文档跳转对应知识库文档。

### 4.4 知识库提问（AI 问答侧边抽屉）
- 入口：顶部"知识库提问"按钮（已勾选 ≥1 个知识库时可用，未勾选置灰）；
- 打开后面板展示已选知识库 chips 及提示"回答将仅基于已选知识库中的资料生成"；
- 对话式问答：输入问题 → 发送 → AI 返回答案，答案可包含引用（点击定位原文）；
- 范围限制：**检索范围 = 已勾选知识库 ∩ 用户有权访问的知识库**，无权限内容不参与检索、不进入回答。

#### AI 问答机制（核心卖点，详细设计）
| 环节 | 说明 |
|---|---|
| 范围圈定 | 用户勾选知识库（或 Enjoy AI 中 `#` 提及/选择器选择），形成本次问答的检索白名单 |
| 权限过滤 | 白名单与用户实际权限求交集；对无权限知识库静默剔除，并在 UI 提示实际生效范围 |
| 召回 | 基于文档解析结果（正文分块 + 分页）进行语义检索，取高相关片段 |
| 生成 | 仅基于召回片段生成回答，不依赖模型通用知识回答业务问题；无相关结果时明确告知"未找到相关内容" |
| 引用溯源 | 每条引用带：来源文档名、页码、原文片段；点击引用跳转文档预览并定位到对应页/片段（原型 `previewBackdrop` 引用定位实现） |
| 失败兜底 | 检索失败/网络异常时给出可重试提示，不返回空白 |

### 4.5 Enjoy AI（独立 AI 对话页）
- 独立页面（导航"Enjoy AI"），对话界面：欢迎语 + 场景建议（分析资料 / 撰写方案 / 知识问答 / 总结会议）；
- **`#` 提及知识库**：输入 `#` 弹出知识库搜索菜单，选中后以标签形式进入问答范围；
- **知识库选择器**（`+` 按钮）：按组织层级分组列出可选知识库，支持"全选组织知识库"；
- 模型标识："Enjoy AI · 通用助手"（模型可切换，原型为静态标识）；
- 回答展示知识库引用，机制同 4.4（检索 → 权限过滤 → 生成 → 溯源）；
- 与"知识库提问"的关系：同一套问答引擎的两种入口 —— 企业知识库页内以"已勾选范围"快速提问，Enjoy AI 页内可自由选择/提及知识库。

### 4.6 成员管理（成员组）
- 成员组卡片网格：组名、成员 chips（头像+姓名+权限）、`···` 菜单（编辑/删除）；
- **新建/编辑成员组**：
  - 组名；
  - 添加成员：两种模式 —— "组织"（勾选组织节点整体添加）/"个人"（组织树勾选或搜索，末级个人可单独勾选）；
  - 已添加成员列表，可分别配置**查看 / 下载 / 管理**权限，高权限包含低权限；
  - 提示：添加"组织"时会**展开为全部人员**（快照式）；已确认行为：勾选组织节点添加后，系统将组织下人员**快照展开**为具体个人成员写入成员组，组织后续人员变动（入职/离职/调岗）**不自动同步**到已建成员组，如需跟随需重新添加或手动更新；
- 成员组可在新建知识库时被引用（"成员组选择"下拉 + 成员预览 + 提示"组内成员将默认获得查看权限"）。

### 4.7 权限管理弹窗
**适用**：知识库权限、文档权限（同一组件，权限项不同）。

- 授权对象类型：**组织 / 个人 / 成员组**；
- **组织级联选择器**：六列级联（集团 → 事业部 → 片区 → 中心 → 部门 → 个人），列内多选，底部"清空 / 添加所选"，顶部展示"N 项已选"；
- 右侧"待添加对象"清单（roster）：显示对象 + 可配置权限项，支持搜索/移除；
- "当前已授权对象"列表：对象名称、来源（管理者/创建者/组织继承/组织团队/单独添加/成员共享）、权限项（勾选式）、移除；
- 保存后权限即时生效。

### 4.8 管理端功能

#### 4.8.1 空间域配置
- 列表：空间域 | 知识库类型 | 所属组织层级（集团/事业部/中心/无）| 状态（启用/停用）| 操作；
- 查询：按名称、状态筛选；支持重置；
- 新建/编辑空间域：名称、知识库类型、所属组织层级、启停状态；
- **岗位知识库子类型即空间域条目**：管理员可新增"鸭脖主业岗位知识库 / 廖记岗位知识库 / 集团岗位知识库"等子类型条目（知识库类型=岗位知识库，组织层级=无），停用后该子类型不再出现在范围树与新建类型选项中；
- 停用后：该类型知识库不可再新建（`allowedCreateLibraryTypes` 过滤），已存在知识库不受影响。

#### 4.8.2 知识库权限（管理页）
- 查询条件：知识库名称、人员名称、知识库类型；支持查询/重置；
- 授权记录列表：人员 | 知识库 | 知识库类型 | 操作（绑定/解绑）；
- "新增管理员"按钮 → 授权知识库管理者弹窗（选择人员 + 管理员类型：集团/公司/中心），提示管理员类型决定可管理的知识库范围。

#### 4.8.3 知识库配置（初始化）
- 列表：全选 | 知识库 | 类型 | 描述 | 管理员 | 默认权限 | 状态（未初始化/已完成初始化）| 操作；
- 查询：名称、类型、初始化状态；
- **新建知识库配置**：知识库名称、类型、所属组织、管理员（搜索姓名/工号/部门）、描述、管理员默认权限（查看/下载/管理）；
- **执行初始化**：勾选配置后批量执行，自动创建知识库并完成管理员/权限初始化；展示执行结果反馈。

#### 4.8.4 知识库管理（授权知识库管理者）
- 统计卡（原型含统计位，待补充指标定义）；
- 管理员列表：人员 | 管理员类型（集团/公司/中心）| 操作（移除）；
- 授权入口：搜索人员（姓名/工号 ≥2 字符）→ 选择管理员类型 → 确认。

#### 4.8.5 我的分享
- 列表：知识库 | 分享对象 | 权限 | 有效期（7/30/90 天 / 长期有效）| 分享来源 | 操作；
- 即将到期标黄、已到期置灰划线；
- 支持**撤回分享**（确认后立即回收授权）。

### 4.9 分享知识库
- 入口：知识库 `···` 菜单"分享知识库"；
- 参数：授权对象（组织 / 个人）+ 搜索选择对象 + 有效期（7 天 / 30 天 / 90 天 / 长期有效）；
- 默认权限：查看；提示"到期后系统自动回收本次分享授权"；
- 分享记录进入"我的分享"可撤回。

## 5. 关键业务规则汇总

| # | 规则 |
|---|---|
| R1 | 岗位知识库为父节点，子类型由空间域配置动态生成（原型预置 3 个），勾选后平铺展示，不在树中展开 |
| R2 | 新建知识库可选类型 = 当前 scope 下启用的知识库类型（受空间域启停约束） |
| R3 | 知识库权限：管理 ⊃ 下载 ⊃ 查看；文档权限：管理 ⊃ 编辑 ⊃ 下载 ⊃ 查看（勾选高级权限自动勾选低级） |
| R4 | 管理员类型决定可管理的知识库类型（集团/公司/中心） |
| R5 | 系统知识库不可删除；仅管理员可删除知识库 |
| R6 | 分享为临时授权，到期自动回收；分享默认仅"查看" |
| R7 | 复制到个人空间生成独立副本，与原文档无关联 |
| R8 | 文档收藏持久化（localStorage 记忆） |
| R9 | 进入文档列表页隐藏顶部全局操作（成员管理/知识库提问/新建知识库） |
| R10 | AI 问答检索范围 = 用户所选知识库 ∩ 用户有权访问的知识库；无权限内容不召回、不回答 |
| R11 | AI 回答必须携带引用（文档名 + 页码 + 原文片段）；无相关结果时明确提示，不编造 |
