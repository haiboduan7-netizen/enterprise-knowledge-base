# 企业AI知识库管理平台

企业级 AI 知识库产品的高保真原型与产品需求文档（PRD）。

## 内容

| 文件 | 说明 |
|---|---|
| `fluxnote-ai-knowledge-base.html` | 高保真交互原型（单文件 HTML，无外部依赖，浏览器直接打开） |
| `docs/PRD-企业知识库管理平台.md` | 产品需求文档 v0.2 |

## 原型功能概览

- 范围筛选树（集团/公司/中心/项目/岗位/个人知识库多选）
- 知识库列表：勾选、全选、批量操作、行级菜单（权限管理/编辑/分享）
- 文档管理：列表、分页、收藏、跨库搜索
- AI 能力：知识库提问（范围限定问答）、Enjoy AI 对话（#提及知识库）
- 管理端：空间域配置、知识库初始化、成员管理（组织快照展开）、我的分享

## 使用

下载 `fluxnote-ai-knowledge-base.html` 后用浏览器直接打开即可，无需构建、无外部依赖。

## 设计规范

浅蓝白企业 SaaS 风格 · 中文界面 · 大屏展示友好
